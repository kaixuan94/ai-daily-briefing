1. AI公司/官方/核心研究者与工程师

1.1 Gemini Decisions API：只做判断、不写回答

  • 核心观点：@sundarpichai 宣布在 Google AI Studio 上线 Gemini Decisions API，模型为 Gemini Decision 1。它不逐 token 生成文本，而是针对封闭选项打分，单次最多 1,000 个问题，输入可以是文本、图片、音频、视频和 PDF。@dotey 的中文整理：返回每道题的答案和置信度，输入每百万 Token $0.1，输出免费；典型场景是客服消息分组、决定交给便宜模型还是推理模型、内容审核。@dongxi_nlp 补充了另一个用法：用 decision model 识别并修正文档解析错误，再把干净数据交给下游 Agent。
  • 关键方法/工具：Gemini Decisions API、Gemini Decision 1；「Agent 路由 / 审核 / 分类 / 文档质检」四类场景。
  • 可行动点：把自家 Agent 里「让大模型写一段话再解析出选项」的调用找出来，改成 Decisions API 一次批量判断，对比成本、延迟和解析失败率；路由时直接用置信度设阈值。
  • 原帖链接：https://x.com/sundarpichai/status/2120581155078729728 ；https://x.com/dotey/status/2120647659388031454 ；https://x.com/dongxi_nlp/status/2120579654126108708
  • 来源标注：【账号池】@sundarpichai、@dotey、@dongxi_nlp

1.3 AlphaGenome 2：预测 DNA 变异在特定细胞类型里的影响

  • 核心观点：@sundarpichai 介绍 AlphaGenome 2，可以预测 DNA 变异对具体细胞类型（如心肌细胞 vs 免疫细胞）的影响，用来寻找疾病的细胞层面驱动因素。@m_goes_distance 把 Google 的生物栈总结为逐层叠加：AlphaFold（蛋白质结构）→ AlphaGenome（DNA 功能）→ AlphaGenome 2（在哪种细胞里发生）→ Isomorphic（药物设计）。
  • 关键方法/工具：AlphaGenome 2；「分层建模生物学」的框架。
  • 可行动点：做 AI + 医疗/生物方向的，可以按这五层梳理自己处在哪一层、上下游数据从哪来。

1.5 工程方法：DDD 统一语言 + 团队共享 Skills

  • 核心观点：@mattpocockuk 说他的课程里最让学员震撼的不是 Agent，而是领域驱动设计（DDD）：先建立一套「统一语言」，和 Agent 对话时用它，再把代码重构成用这套语言命名。他的延伸观点：如果你能用清晰、一致的语言描述业务流程，自动化软件就已经做了一半。@housecor 主张少用个人 Skills、多用团队共享 Skills，避免流程碎片化和开发效率差异过大。@kentcdodds 提醒：你的电脑上有多少把密钥，一个误解指令的 Agent 就能拿来搞垮生产环境。
  • 关键方法/工具：DDD ubiquitous language、团队共享 skill 库、最小权限密钥。
  • 可行动点：给你的项目写一页「术语表」放进仓库，让 Agent 每次先读；把个人好用的 skill 提交到共享目录；检查本机 .env 和 CLI 登录里有没有生产库写权限。
  • 原帖链接：https://x.com/mattpocockuk/status/2120503390333768170 ；https://x.com/mattpocockuk/status/2120606575819956439 ；https://x.com/housecor/status/2120525804647919835 ；https://x.com/kentcdodds/status/2120548188730069301
