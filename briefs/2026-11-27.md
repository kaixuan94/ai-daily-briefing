## 2. 中文AI落地/独立开发/一人公司(OPC)/超级个体

### 2.1 范凯：先按场景选入口，再谈模型谁当主力（核心 KOL）

- **核心观点**：@fankaishuoai 把最近自己的用法收成一套很清楚的分工：本地多 Agent 编排选 Paseo，云端商业 Bot 选 Grok Bot，本地自托管选 Hermes。这不是在宣布「唯一正确答案」，而是按使用场景选入口。模型侧，他把 GPT-6.2 Sol 当成一号主力（便宜、质量够用、开 Fast 后速度快，已经替代他此前最常用的 DeepSeek，成为「苦力模型」），Gemini 4 Neon 升到二号，DeepSeek V4.1 Flash 退居备胎。具体搭配是：日常用 Pi + GPT-6.2 Sol；第二主力是 Antigravity + Gemini 4 Neon；编程用 Pi + GPT-6 Astra（high）；关键决策用 Pi + GPT-6 Astra（xhigh）。Neon 还当不了第一，是因为推理服务不够稳定，出现过多次长时间挂起；更麻烦的是过程不透明——你不知道它是卡死了，还是还在跑。他另外观察到：Neon 几乎不输出中间的思考和工具调用，只在最后一次性给出结果，体感就是等得很久、一旦开始又出得很快。他猜测这是为了防止被蒸馏。与此同时，GPT 订阅额度「完全用不完」，12 月还有多次重置和积分，他反而提醒自己要开 Astra 和 Ultra Fast，否则会觉得浪费。
- **关键方法/工具**：按「本地编排 / 云端商业 Bot / 自托管」拆入口，而不是让一个壳覆盖所有场景；用稳定性、过程可见性，而不是峰值分数，决定谁当主力。
- **可行动点**：先写下自己最常见的三类工作（日常苦力、编程、关键决策），看它们是否被塞进同一个模型里；如果是，试着按场景拆开，并观察哪一类最不能容忍「挂起却看不到过程」。
- **原帖链接**：https://x.com/fankaishuoai/status/2126122477046927455 ；https://x.com/fankaishuoai/status/2125915602707788119 ；https://x.com/fankaishuoai/status/2125950515200860163 ；https://x.com/fankaishuoai/status/2125850993506304147
- **来源标注**：【核心 KOL】@fankaishuoai

### 2.2 范凯：Gemini 订阅套餐是给人用手用的，不是拿来跑自动化的（核心 KOL）

- **核心观点**：面对有人一天内被封号、并怀疑是 Paseo 的问题，@fankaishuoai 把原则说得很直：即使用 ACP，高频自动化、高并发一样会封，和是不是 Paseo 无关。他给出的「正确姿势」有三条：必须通过 ACP 调用，反向代理或 hack OAuth 会封；不能让 Pi、Codex、Claude Code 这类 Agent Harness 直接去调 Antigravity；不要搞自动化——订阅套餐是手工使用的瘦客户端，高频自动循环也可能触发封号。Paseo 里经 ACP 用 Antigravity，正常使用他认为是合规的；但如果你自己起 n 个 session 去跑循环，仍可能被封。他同时下线了插件里查询 Gemini 额度的功能，因为 Google 明确不能在软件中封装 `acp -p` 调用。他补充：T3 虽然也是 ACP，但又用了 OAuth，风险更高。他还提到，12 月 2 日之后，这些规则可能会过期，Gemini 订阅套餐或许会放开给第三方 Agent——这是原帖中的前瞻，不是已经发生的政策。
- **关键方法/工具**：把「官方认证的瘦客户端 + ACP + 人工节奏」当成订阅套餐的使用边界；把自动化并发当成额外风险，而不是默认能力。
- **可行动点**：如果最近在用 Gemini 订阅跑 Agent，先检查自己有没有把它当成算力农场：同时开了多少 session、有没有循环重试。有，就先降到手工能跟住的节奏，再谈效率。
- **原帖链接**：https://x.com/fankaishuoai/status/2125881651704238271 ；https://x.com/fankaishuoai/status/2125845272379204090 ；https://x.com/fankaishuoai/status/2125913709113729092
- **来源标注**：【核心 KOL】@fankaishuoai

### 2.3 橘子：真正赚钱的 AI 应用，往往长得像一艘一起划的小船

- **核心观点**：@oran_ge 在新一期「橘座」里请来星月写作 CEO 猛哥。原帖给出的事实是：猛哥创业十年，从 2015 年做 VR 游戏到 2023 年做 AI，做出了三款月入百万、且都有利润的 AI 应用；其中星月写作去年收入破千万，有一千多个用户拿到月入过万的稿费，其中一半多以前从没写过小说。猛哥把产品形容成一艘小船：上了船的人一起划、一起赚钱。这期节目聊的是他一路上的关键决策，以及做成之后更大的梦想是什么。对「环境这么差，怎么做出真正赚钱的 AI 应用」这个问题，它提供的不是一句口号，而是一个可核对的样本：先有利润，再有分成式的用户获利，而不是先讲模型有多强。
- **关键方法/工具**：用「产品是否已经有利润、用户是否也从中赚到钱」来判断一个 AI 应用是不是真的立住了；把访谈当决策复盘，而不是当成功学。
- **可行动点**：若你在做或评估一个 AI 产品，先写下两行：它现在靠什么产生利润；用户付费之后，自己能不能讲清楚他们得到了什么可核对的结果。

### 2.4 最省事的尽调：问创始人自己用不用（账号池）

- **核心观点**：@Bencera 写了两条很短、但可直接拿来用的检验。第一条：对任何 AI 创业公司，最容易的尽调就是问创始人，自己的公司是不是跑在这套产品上；然后看他们多久开始转移话题。第二条：没有人会偷走你的想法——他们得先熬过「前六个月什么都还不灵」的那段。两条合在一起，针对的是同一种幻觉：把「点子」和「演示」看得太重，把「自己是否真的依赖它、以及有没有熬过失灵期」看得太轻。
- **关键方法/工具**：用「创始人是否把公司跑在自己的产品上」做第一轮过滤；用「前六个月失灵是否可承受」来评估想法的真实壁垒。
- **可行动点**：下次听产品演示时，先问一句「你们自己的流程哪一步已经换成这个了」；答不清楚，就先不要根据演示做判断。
- **原帖链接**：https://x.com/Bencera/status/2125960350772449574 ；https://x.com/Bencera/status/2125939773974220960
- **来源标注**：【账号池】@Bencera

### 2.5 提示词对模型未必最重要，对人仍然最重要

- **核心观点**：@xiaohu 的判断是：提示词可能不再是对 AI 最重要的事情，但对人仍然最重要。原因不是模型不够聪明，而是绝大部分人脑袋空空——既不知道自己想要什么，也不知道该怎么问。学会提问本身就是一件复杂的事。同一窗口，@vista8 分享了一个「非常傻的懒人提示词」：当网站做出来了，却不知道如何美化、该加什么功能时，直接对 AI 说「继续迭代优化，让网站更好用，更好看，更有价值。」他用 Gemini Neon 试了一次，模型不但改了 CSS，还补上了一键 Homebrew 装机指令。两条看起来一紧一松，指向的是同一件事：提问能力决定上限；但在你还说不清要什么的时候，先给一个明确的迭代方向，也比停在空白处强。
- **关键方法/工具**：把「学会提问」当成对人的训练，而不是只当成调模型的技巧；在需求模糊时，用一句清楚的迭代目标推动下一轮，而不是空等完美规格。
- **可行动点**：选一个你已经做出来、但一直不知道下一步的半成品，只用一句「让它更好用、更好看、更有价值」做一轮迭代，然后写下你自己真正喜欢和真正讨厌的变化——这会倒逼你看清想要什么。
- **原帖链接**：https://x.com/xiaohu/status/2125879936913375669 ；https://x.com/vista8/status/2125929542032457784
- **来源标注**：【账号池】@xiaohu、@vista8

## 3. AI视频/生成工具/创意内容

### 3.1 Sac：纸艺立体书是一种可复制的起号风格（核心 KOL）

- **核心观点**：@Saccc_c 推荐了一种他新发现的、自认为适合自媒体起号的视频风格：纸艺立体书。他自己用这套风格做了《小王子》故事，场景来自他的游戏改编。他强调的不只是「好看」，而是这种风格既有审美、又偏治愈，觉得能有超高热度。方法也很具体：把 Github 仓库链接一键复制给 Agent 即可开始做。仓库来自 @xikhar，地址为 https://github.com/xikhar/papercraft 。这是一条带方法和可复用资产的实践帖，而不是只晒成品。
- **关键方法/工具**：纸艺立体书风格 + `xikhar/papercraft` 仓库，直接交给 Agent 复刻。
- **可行动点**：若你在尝试用 AI 视频做内容，先不要从零描述风格；可以直接把该仓库交给 Agent，先复刻一条短样，再判断自己是否拿得出差异化的故事。
- **原帖链接**：https://x.com/Saccc_c/status/2125905907926360555 ；仓库：https://github.com/xikhar/papercraft
- **来源标注**：【核心 KOL】@Saccc_c

### 3.2 Sac：不用建模工具，用 HungerG 纯代码做城市微缩动画（核心 KOL）

- **核心观点**：@Saccc_c 用免费匿名模型 HungerG，在不调用任何建模工具的情况下，纯代码做了一段深圳城市微缩动画：从 1979 年的小渔村讲到今天，风格是手工树脂。他的评价重点不在极致精细，而在材质、灯光氛围和年代之间的转场；他认为这很适合用来快速测试一个模型的审美能力。实测里，他特别提到指令遵循和持续迭代：只要提示词足够具体、迭代目标明确，模型就能基于上一轮结果，改掉当前最大的不足。评论区给出了可复用的提示词框架：以风格参考图为准，复刻画风和布局，再吸收实拍场景中不同年代的内容，做一条约 40 秒、横版 16:9 的短片，讲同一块海边土地的生长。他称该模型当时还剩约 5 天免费体验，入口是 Qoder 或 OpenCode。
- **关键方法/工具**：用「风格参考图 + 实拍资料 + 明确时长和画幅 + 单一叙事主线」写提示词；把模型的迭代能力当成工作流的一部分，而不是一次生成碰运气。
- **可行动点**：若要测试一个新的图像/代码模型好不好看，不要只丢一句「做个城市动画」；选一个你熟悉的地点，准备 1 张风格图和 2–3 张实拍，写清时长和转场目标，再看它能不能在第二轮改掉第一轮最明显的毛病。
- **原帖链接**：https://x.com/Saccc_c/status/2125835479220380138 ；提示词：https://x.com/Saccc_c/status/2125835483326324800
- **来源标注**：【核心 KOL】@Saccc_c

## 4. Crypto/Web3/投资/交易

### 4.1 账面 18% 可能更贵；借钱前先问「未来的我要向谁请示」（优先监控）

- **核心观点**：@safalniveshak 先指出一个纸面上几乎没人会反对的排序：18% 的回报永远压过 12%。但他马上把问题从「哪个数字更大」改成「你为这个数字付出了什么」：真实生活里，有时更高的账面回报反而更贵。具体论证在原帖的 68 秒视频中；本轮未能可靠转写该视频，这里不补充视频里没有写在文字中的例子或数字。同一窗口他还写了一句更完整、可直接使用的问题：利率只告诉你贷款成本的一部分；借钱之前，更值得问的是——「未来的我，哪些决定需要先得到债权人的允许？」这把债务从「每月要付多少」改写成了「未来的自由度会被谁锁住」。
- **关键方法/工具**：比较回报时，把波动、约束、心理代价和生活自由度算进去，而不是只看年化数字；借钱时先列出未来哪些决定需要债权人点头。
- **可行动点**：若正在比较两个投资或一笔贷款，先写三行：账面回报或利率、你为它放弃的灵活性、以及未来哪类决定可能要先征求别人同意。写不出来，就还没把成本看全。

### 5.1 客户即使说满意，也仍会「漂亮地不满足」（优先监控）

- **可行动点**：选一个你最近觉得「已经够好」的产品、流程或投资框架，写下它一年前让你惊喜、现在却习以为常的两点；这往往就是下一轮该被审视的地方。

### 5.2 有一种性格，在又大又慢的组织里活不下去（优先监控）

### 5.7 三个发现：仪式、幸福的回落，以及分数不再等于学习（优先监控）

- **核心观点**：@robkhenderson 在每周链接汇总里列了三条发现（均为他的转述，不是他本人的研究）。第一，与从不参加宗教仪式的人相比，每周至少参加一次的人全因死亡风险低 26%，也更不容易抑郁和焦虑。第二，人们追逐金钱、地位和财物，希望得到持久幸福，却往往回到原来的基线；一个被他点名的例外是整容，相关者报告情绪收益会持续。第三，成绩单常常不再反映孩子真正学到了什么：在 SAT 和 ACT 分布最底部的考生里，分别有 44% 和 33% 的人报告自己在高中一直拿 A。三条不必接受全部结论，但共同指向一件事：我们用来自我安慰的指标（感觉、财富、分数）经常和真实结果脱节。
- **关键方法/工具**：把「公开指标」和「真实结果」分开核对；对幸福、成绩和健康这类容易被包装的对象，优先看持续跟踪的研究，而不是单次故事。
- **可行动点**：选一个你正在用来评价自己或孩子的指标（成绩、收入、点赞、自我感觉），问它最近一次和真实能力或真实健康对过表没有。

## 6. 身心整合/终身学习/超级个体补充

### 6.1 每周一次的仪式，和死亡率、情绪的关系（优先监控）

- **核心观点**：接上条第一条发现：@robkhenderson 转述，与从不参加宗教仪式的人相比，每周至少参加一次的人全因死亡风险低 26%，抑郁和焦虑也更少。这不是让人去「为了长寿而信教」，也没有在原帖里被证明为因果关系。它更适合被看成一条关于节奏和连接的线索：稳定出现在一个共同体里、有重复的仪式，可能和身体与情绪的结果一起出现。对已经有跑步、拳击或家庭晚餐这类固定节奏的人，它的启发不必是改信仰，而是不要轻易拆掉那些让你定期出现在他人面前的安排。
- **关键方法/工具**：把每周重复、且与他人共在的仪式，当成健康相关的变量来观察，而不是只当成兴趣爱好。
- **可行动点**：检查自己是否至少有一件每周都会发生、且必须离开房间与他人共在的事；没有的话，先恢复或建立一个，再谈其他优化。

### 6.2 六件小事，用来给大脑新的可适应对象（账号池）

- **核心观点**：@alexeixbt 写：大脑在持续变化，正确的日常习惯可以帮助重塑思维。他列了六步：每天花两分钟想象未来的自己如何思考、行动、过日常；捕捉自己缩小格局、犹豫或觉得自己不行的瞬间并写下来；每天改写一个限制性信念，例如把「我还没准备好」换成「我可以边做边学」，并且用行动去证明；真正感受感恩，不只是报出「家庭」或「房子」，而要想起为什么、停在那种安全与被关心的感觉里；用行动给大脑证据——想更有自信就今天发言，想更有纪律就兑现一个小承诺；最后，调节神经系统，每天留出平静：走路、慢呼吸、离开手机几分钟，不要全天停在生存模式。他的收束是：不要等自己先感觉像另一个人，再开始行动；先按那个样子做一次小决定。
- **关键方法/工具**：想象未来自我、记录自我设限、改写信念并配上行动、认真感受感恩、用小承诺提供证据、每天给神经系统复位。
- **可行动点**：今天只做清单里的两件：写一次你缩小格局的瞬间，再兑现一个当天能完成的小承诺。不要六件一起上。

### 6.3 把事情变得有趣，不是幼稚，是为了让脑子更好用（账号池）

- **核心观点**：@alexeixbt 说，激活一点「whimsy」（俏皮、好玩）是高级的大脑技巧；把生活里每件事都搞得很严肃，反而可能让人更笨。他给的机制是：好玩会提高多巴胺，任务更容易被启动，也更容易进入心流；心情好时，大脑对可能性和解决方案更开放。反过来，一切都必须按某种方式完成时，神经系统会收紧，认知灵活性下降，动机也更弱。长期压力抬高皮质醇，还可能影响前额叶——他称之为大脑的「CEO」。所以他问的不是「你该不该认真」，而是：今天的任务怎样可以变得更好玩一点，好让你可能做得更好。同一窗口他还写了一条很具体的 ADHD 相关经验：在真正做完之前，不要把打算告诉别人——一旦说出口，大脑会提前得到多巴胺和完成感，随后就失去做完它的动力。
- **关键方法/工具**：给任务增加一点趣味，以提高启动和灵活性；对容易「说完就不做」的人，先做完再宣布。
- **可行动点**：选一件你今天在拖延的事，只改两个变量：让它变得稍微好玩一点，以及在完成前不对任何人预告。

### 6.4 没人相信你，有时反而保住了独立（优先监控）
