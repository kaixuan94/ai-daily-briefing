  • 核心观点：@cishanjia 复盘过去一年：平均每天学 2–3 小时英语，现在开始用全英文读会计专业（「会计是商业的通用语言」——巴菲特）。理由是直接用英语学习投资和前沿论文更方便。这一年没有买过任何币，时间都花在英语、投资书和健身上；读完巴菲特和芒格后发现，很多困惑「真的就是书读少了」。
  • 关键方法/工具：固定日均时长的长期语言训练；用目标语言学一门专业课，以学代练。
  • 可行动点：选一门你需要的专业课（如会计、统计），用英文教材学 30 天，每天固定时段。
  • 原帖链接：https://x.com/cishanjia/status/2120140755679555674
  • 来源标注：【账号池】@cishanjia

6.2 降低认知负荷：ADHD 友好习惯 + 让 Agent 主动帮你减负的一条提示词

  • 核心观点：@alexeixbt 整理给有 ADHD 倾向者的习惯：减少认知负荷（手机拿出房间、关掉多余标签页、清空桌面，「你的大脑打不过十几个刺激源，别把这当成自律问题」）；保护工作记忆（任务一出现就写下来，以免忘掉）。他还推荐了 Lara Boyd 博士讲任何年龄都能重塑大脑的视频。@AlexFinn 分享一条提示词，让 Agent 根据对你的了解，主动提出能减轻你认知负荷的系统、子 Agent 或例行任务（原文：「My goal for working with you is to lighten my cognitive load…」）。他的北极星是工作量不变、腾出更多脑力空间。
  • 关键方法/工具：环境减刺激 + 外部化工作记忆；「减轻认知负荷」提示词。
  • 可行动点：今天把手机放在另一个房间工作 90 分钟；把 AlexFinn 的提示词发给你的 Agent，从它的建议里挑 1 条落地为每日例行任务。
  • 原帖链接：https://x.com/alexeixbt/status/2120188813334946215 ；https://x.com/alexeixbt/status/2120212286178738662 ；https://x.com/AlexFinn/status/2120316818132984120
  • 来源标注：【账号池】@alexeixbt、@AlexFinn

6.3 AI 与应届生：基础活被 AI 做完之后，从哪里开始学

  • 核心观点：@MindfulReturn 引用国务院办公厅 10 月下旬印发的《关于适应人工智能技术发展助力构建就业友好型发展方式的意见》（要求稳慎把握 AI 在劳动密集型行业应用的范围、力度、节奏），以及澎湃商学院的追问：AI 把基础活干完后，应届生从哪里开始学。他认为文中引用的 Anthropic 今年 1 月的实验比任何观点都更有说服力（细节见原帖）。
  • 关键方法/工具：把「判断和验收能力」而不是「执行速度」作为新人培养重点。
  • 可行动点：带新人的管理者，让新人先当 AI 产出的审核者（找错、给出验收标准），再逐步承担执行。
  • 原帖链接：https://x.com/MindfulReturn/status/2120073808291963124
  • 来源标注：【核心KOL】@MindfulReturn 身心修复局

7. 媒体/工具/其他

7.1 Lenny 2026 下半年科技就业报告：PM 开放岗位四年最多，工程停滞，设计创新低

  • 核心观点：@dotey 的中文整理：PM 开放岗位 7,303 个，比 2023 年 3 月低点多 75%；工程开放岗位首次停止增长（过去一年仅 +2.5%，现有 65,351 个），过去 12 个月美国实际招聘软件工程师约 11.3 万，不到 2022 年高峰的一半。工程师内部分化明显：前线部署工程师（FDE）开放岗位增至 4.6 倍（约 1,450 个），安全 +34%，平台 +30%；前端 −51%，Android −47%，iOS −46%。产品设计开放岗位 1,924 个，为有记录以来最低。PM 招聘启事里出现最多的技能变成「LLM」（11%），Claude 排第三（5%）。湾区占全球科技开放岗位的 14.9%，创纪录；可远程岗位只剩 14.4%。
  • 关键方法/工具：TrueUp（开放岗位）+ Live Data Technologies（实际入职）两套口径。
  • 可行动点：工程师优先补 FDE、安全、平台方向的能力；简历里写清楚 LLM、Claude、Cursor、MCP 的实际项目经历。
  • 原帖链接：https://x.com/dotey/status/2120226054195577277
  • 来源标注：【账号池】@dotey

7.2 工具箱：IconMCP、MiaoYan + CLI、Modern Web Guidance 1.0、Pi 扩展生态

  • 核心观点：@dingyi：IconMCP 免费提供 6,248 个原创线框和实心图标，可复制 SVG、下载 PNG，也能让 Agent 直接找图标；官网称由 AI Agent 持续绘制新图标，目标 10 万个。@HiTw93：MiaoYan 是原生的 Mac/iPad/iPhone Markdown 笔记应用，笔记是纯 Markdown 文件，miao CLI 让 Agent 可以搜索、读取和添加笔记。@sarah_edo：Modern Web Guidance 1.0 是一组经行业专家审核的 skills，帮编码模型绕开过时的训练数据，覆盖性能、无障碍和安全（npx modern-web-guidance@latest install）。@GitTrend0x 盘点 Pi 扩展：pi-mcp-extension 能把 Pi 接到任意 MCP 服务器（stdio/SSE/Streamable HTTP，支持 OAuth 2.1）；pi-advisor 让快模型干活，卡住时再请更强的模型把关。@xiaomovps 解读 HN 热帖《Goodbye Claude, Hello Pi》：作者统计 Claude Code 截至 9 月发布了 244 个版本，75% 以上改过系统提示词或工具描述，影响工作流稳定性；Pi 更精简，用扩展自己解决问题，代价是安全审批和扩展审核要自己负责。
  • 关键方法/工具：IconMCP、MiaoYan（miao CLI）、Modern Web Guidance、Pi + pi-mcp-extension / pi-advisor。
  • 可行动点：做前端的给 Agent 装上 MWG skills，并装 IconMCP 替代手动找图标；重度定制 Agent 的开发者，可以用 Pi + pi-advisor 搭一套「便宜模型执行、贵模型把关」的流程。
  • 原帖链接：https://x.com/dingyi/status/2120079767814996447 ；https://x.com/HiTw93/status/2120170548722651600 ；https://x.com/sarah_edo/status/2120202137200218314 ；https://x.com/GitTrend0x/status/2120048957216772216 ；https://x.com/xiaomovps/status/2120087420582646246
  • 来源标注：【账号池】@dingyi、@HiTw93、@sarah_edo、@GitTrend0x、@xiaomovps

7.3 平台动态：Telegram 消息变成小应用；X 重写 Web 前端

  • 核心观点：@durov：任何 Telegram 消息现在都可以变成一个应用，体积不到 4 KB，原生渲染、可交互，内置支付和病毒传播机制，开发者可以自己构建（附开发文档）。@vikingmute 推荐 X 工程师的文章《Rebuilding the global town square from scratch》，讲 X 如何彻底重写 Web 前端，解决性能和架构问题。
  • 关键方法/工具：Telegram 消息内应用；大型前端重写案例。
  • 可行动点：做社群或 Crypto 增长的，可以评估把抽奖、投票、支付做成「消息内应用」；前端工程师可以把 X 的文章作为性能重构参考。
  • 原帖链接：https://x.com/durov/status/2120148866469376463 ；https://x.com/vikingmute/status/2120147236202192971
