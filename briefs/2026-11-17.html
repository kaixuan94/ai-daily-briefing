2.1 卡兹克最常用的两句 Agent Prompt

  • 核心观点：@Khazix0918 翻了近两个月用 Agent 干活最爱说的话：①「从第一性原理出发，找到最本质原因，修复一下。」②「先问一些不清晰的问题，对齐我的喜好，然后再出 3 版方案。」（近 3000 赞、3200+ 收藏，今日收藏最高）。@AlexFinn 同一思路：动手前让模型尽可能多地反问你，比 plan mode 只问 3–4 个问题更彻底，他称 AI 编程提速 20 倍。
  • 关键方法/工具：第一性原理修 bug；先反问对齐 → 多版方案。
  • 可行动点：把这两句存成常用 prompt 或 skill；下次开新项目，先让模型连续反问直到问不出问题再开工。

2.2 主会话做路由、Thread 做执行，Token 并不贵

  • 核心观点：@dotey：「主会话 + Thread」模式优化好了，Token 消耗不高。主会话不需要最强模型，Sonnet 5.5 级别就够，它的职责是甄别和路由，像公司前台；具体任务交给 Thread。后续补充：这说的是 Bot 类应用的主会话（所有消息都发进来），不是单个研究型任务。
  • 关键方法/工具：主会话（便宜模型路由）+ Thread（强模型执行）。
  • 可行动点：检查自己的 Bot 主会话是不是用了过贵的模型；把执行类任务拆到子线程。
