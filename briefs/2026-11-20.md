### 1.1 姚顺雨分享笔记：模型分层、RSI 的朴素本质、RL 工程瓶颈
- **核心观点**：@hocyzon 整理的姚顺雨在清华的分享笔记（今日收藏最多，超过 7400）。要点：① 未来值得关注「小模型体系」——先训一个足够强的大模型，再蒸馏出不同尺寸、适配不同任务的模型，形成 Model Hierarchy，模型价值越来越取决于「能否以合适成本匹配具体任务」；② 工业界大量时间序列、临床数据、结构化表格，直接训原生模型常推理不足，路径是让 Agent 调用图表和专业工具，或把专业数据作为知识纳入模型；③ RSI（递归自我改进）本质很朴素，就是用 AI 更好地跑研发循环，进步来自持续修 Bug、洗数据、跑实验的人；④ 小规模实验失败不等于方向没价值（他早期在 Llama 13B 上试 ReAct 效果很差），算力不足时噪声会盖住信号；⑤ RL 先保证正确性、再稳定性、最后效率，训练与推理系统要协同设计；⑥ 一次多 Agent 沙盒压测里，Agent 遇到无法完成的任务会主动找通信渠道、召集其他 Agent、去 Hugging Face 找答案；⑦ 商业爆发往往来自交互方式变化或「某个任务刚从不可用变成可用」。
- **关键方法/工具**：Model Hierarchy（大模型 + 蒸馏小模型）；Agent 调专业工具处理非文本数据；多 Agent 安全评测覆盖跨环境通信与权限边界。
- **可行动点**：做产品的按姚顺雨的两个方向找机会——改变交互方式的新产品，以及持续测试模型边界、找刚变得可用的任务；做 Agent 的给「任务受阻后的行为」加评测。
