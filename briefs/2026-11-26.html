2. 中文AI落地/独立开发/一人公司(OPC)/超级个体

2.1 范凯：Harness 没有护城河，真正要守的是入口和编排（核心 KOL）

  • 核心观点：@fankaishuoai 写了一段自己的工具迁徙史：从 Claude Code 到 OpenCode，再因订阅限制回到 Claude Code；账号被封后改用 Codex + GPT；后来迁到 Pi Agent，中间试过 DeepSeek Harness，为了 Opus 5.5 装过 Copilot，也自托管过 Hermes，现在又「捏着鼻子」用 Antigravity 跑 Gemini 4 Neon。外人看起来像是每天在换壳，他自己的答案是：从头到尾只用 Paseo，由它接入上述这些 Agent，并在多 Agent、多机器、多端之间统一调度。由此得出的判断是——Harness 本身没什么护城河，有护城河的还是 LLM；对用户来说，真正的入口是能把多个 Agent 编排起来的软件。同一窗口他还演示了一个具体用法：把四个有固定角色的 Bot 拉进一个群，点名一个自我介绍、再点名下一个，也可以把任务丢进群让它们自己分工。这是昨天「Bot 对 Agent」那篇长文的继续，重点从「为什么换」推进到「入口应该长什么样」。
  • 关键方法/工具：Paseo 作为多 Agent 编排层（他强调无遥测、可自建加密中继、有插件市场；作者 @moboudra 一人全职维护，并称曾拒绝融资以保持中立）；固定角色的 Bot 进群分工。
  • 可行动点：与其追下一款 Harness，不如先问：自己重复出现的角色和技能，能不能沉淀在一个不跟单一模型绑定的入口里；如果今天换掉底层模型或壳，流程是否还在。

2.2 身心修复局：换掉 Agent，企业的本事还在不在（核心 KOL）

  • 核心观点：@MindfulReturn 认为，创业团队做个人消费级 Personal Agent 会很难，机会更可能在企业级。原因不是模型谁更聪明，而是企业天生希望自己掌握数据，而不是交给大厂。PA 要成立，得让每个人的数据能留存；企业里每一次异常处理、每一次人工确认，都应变成新资产——变厚的是资产，不是模型。判断一份「智能体产品」到底是不是外包，不必事后去算交付成本，看一件事就够：换掉 Agent，企业的本事还在不在。在，才是产品；不在，叫什么名字都是外包。
  • 关键方法/工具：用「数据是否留存、异常和确认是否沉淀为资产」来评估 PA；用「换掉 Agent 之后能力是否还在」做验收标准。
  • 可行动点：若你在用或打算做一套 Agent，列三样离开这套工具后仍属于你的东西（数据、规则、案例）。列不出来，就要警惕自己其实在租一套外包。
  • 原帖链接：https://x.com/MindfulReturn/status/2125535572328690112
  • 来源标注：【核心 KOL】@MindfulReturn

2.3 把「干活的 Agent」和「改知识库的馆长」拆开

  • 核心观点：@xiaohu 转述 LangChain 内部的「知识工厂」做法。让 Agent 在公司里干活，最大的麻烦不是它不会写，而是它不懂内部规矩：指标怎么算、数据去哪张表、文档用哪版页眉——这些散在老员工脑子和聊天记录里，Agent 每次开工都像第一天入职。他们的拆法是：白天干活的 Agent 遇到对不上的规矩，像提工单一样标出哪里错、建议怎么改，然后继续把眼前的活做完；后台另设一个按固定节奏跑的「馆长 Agent」，统一翻看这些标记和运行轨迹，对照 Slack、Notion 里的原始资料，再更新技能和文档。专门拆开的原因很直接：如果让干活的 Agent 顺手改知识库，它一心想把眼前任务交差，规则容易被改乱；全靠人维护又是无底洞。知识库里也不必搬空所有数据，数据底座里已有正本的，放原处现查；库里主要攒三样：按公司规矩做事的技能、核心业务知识，以及写法规范。
  • 关键方法/工具：执行 Agent 与维护知识库的「馆长 Agent」职责分离；报错标记 + 定期回写技能，而不是边干边改规则。
  • 可行动点：若已经让 Agent 参与重复工作，先禁止它直接改「官方规矩」，改成「先标记、再由单独流程更新」，观察规则会不会少打架。
  • 原帖链接：https://x.com/xiaohu/status/2125482662278390081
  • 来源标注：【账号池】@xiaohu

2.4 Bencera：一次产品发布，怎样在前 60 分钟把节奏打起来

  • 核心观点：@Bencera 公开自己为 Polsia 做 Twitter 发布的 6 步打法，并称这条路径曾带来超过 1000 万的发布浏览（此为原帖口径）。步骤并不神秘，但写得很可执行：有东西上线就发布（功能、融资、模型接入、收购等），尽量每月一次；花大量时间写能让自己停下来的钩子，并加上 YC、基金、收入一类的社会证明；视频要做得耐看，而不是底部漏斗式的产品演示；不要等算法来救，主动找人引用、评论和收藏，用前 60 分钟的互动决定能不能进新闻区；必要时为放大付费，或在没有预算时想别的办法把启动做扎实。这是一份增长手册，不是「内容本身自然传播」的神话。
  • 关键方法/工具：发布由头 → 钩子与社会证明 → 耐看视频 → 主动要互动 → 死磕前 60 分钟 → 有预算再做放大。
  • 可行动点：下次发产品或文章之前，先写清「前一小时谁会互动、互动从哪来」，再决定发不发；不要把冷启动全部交给平台推荐。
  • 原帖链接：https://x.com/Bencera/status/2125557946398478378
  • 来源标注：【账号池】@Bencera

3. AI视频/生成工具/创意内容

3.1 Sac：Blender 白模 + MAGI-2，15 秒 1080p 赛车片不到 1.2 美元（核心 KOL）

  • 核心观点：@Saccc_c 把昨天那条「单位成本样本」补成了可跟随的步骤。他展示的 15 秒 1080p 赛车风格成片，称成本不到 1.2 美元（此为创作者单次展示口径，未含自己的建模和调参时间）。工作流分三步：先在 Higgsfield 生成场景图，尽量出多视图，再让 Agent 调用 Blender CLI 按参考图搭场景；人物不必精细，圆柱体即可，重点是规定运动规律和运镜，并在 Blender 里先用白模预演；最后把人物与场景参考图传到 Higgsfield，或在 Agent 里调用其 API，按参考图和白模出成片。同一窗口他还给了一个音频补丁：Fable 5.2 和 Opus 5.5 已经能做出代码生成的视频，但原声音轨仍差，他用 Sonilo 重做配乐和音效，同一画面前后观感完全不同。这不是模型评测，而是一条「一人做短片」能算清成本、也能拆开步骤的实践记录。
  • 关键方法/工具：Higgsfield 多视图场景图；Agent + Blender CLI 搭白模并预演运镜；MAGI-2 按白模出片；Sonilo 重做音轨。
  • 可行动点：若在评估短剧或三维动画的成本，按官方单价自己算一遍 15 秒/分钟，并先在 Blender 里把运动和镜头预演对，再决定是否把成片交给生成模型；不要把单条展示片直接外推成稳定量产品质。
  • 原帖链接：https://x.com/Saccc_c/status/2125749247203275000 ；音频补丁：https://x.com/Saccc_c/status/2125409139186905337
  • 来源标注：【核心 KOL】@Saccc_c

4.1 达里奥：人们常把伟大的新技术，误当成伟大的投资

  • 核心观点：@TechFlowPost 转述 Ray Dalio 最新专访里的警示：当下整个资本市场和宏观经济的希望，都过度押在 AI 上；一旦资产落入脆弱之手，反向循环的破坏力会超乎想象。他拿 1920 年代对比——电网进入千家万户，电灯、冰箱、商业广播、流水线汽车和民用飞机集中出现，技术对人生活的改变甚至比今天的 AI 更直观，但资本仍然经历了大出清。在他看来，泡沫从狂欢到破裂的路径很相似：先是对新技术深信不疑，借贷加杠杆抢购，账面财富爆发；但纸面财富无法直接消费，利率上升或面临还债与税负时，大家会在同一时刻需要法定现金。当资本过度集中于单一技术叙事，所有权从长期持有者转到高杠杆投机者手中；泡沫被戳破后，过度自信会瞬间变成恐慌，去杠杆踩踏会把市场推向另一个极端。这是历史类比和一位投资者的框架，不是对某一资产下一步的预测。
  • 关键方法/工具：把「技术是否改变世界」和「持有该叙事的人是谁、杠杆有多高、会不会同时要现金」分成两问；关注所有权是否已从长期资金转到脆弱之手。
  • 可行动点：复盘自己的组合时，先标出哪些仓位的定价最终依赖同一条 AI 资本开支叙事，再问这些仓位在谁手里、有没有杠杆。不要只用「技术很伟大」当作持有理由。
  • 原帖链接：https://x.com/TechFlowPost/status/2125540824771420381
  • 来源标注：【账号池】@TechFlowPost

4.2 三年大涨之后的个位数年份；市场通常会得到它想要的（优先监控）

  • 核心观点：@awealthofcs（Ben Carlson）给出一组按年回报（原帖口径）：标普 500 在 2023、2024、2025 年分别约 +26.1%、+24.9%、+17.8%，2026 年迄今约 +3.1%；纳斯达克 100 则约为 +54.9%、+25.6%、+20.8%，2026 年迄今约 -0.2%。数字本身不解释原因，但把「高回报是常态」这个错觉拆掉了。同一天他的 Animal Spirits 节目把上周称作一次「AI 暴跌消防演习」，并讨论估值是否已经便宜、这是不是一次健康回调，以及政府介入风险。他在另一篇随笔《The Most Powerful Force on Earth》里把黄仁勋复职写成案例：股票市场往往能得到它想要的——2008 年众议院否决 TARP 当天市场大跌，方案随后通过；2020 年疫情暴跌促使财政和货币迅速出手；去年关税宣布后的急跌，也带来了暂停。他认为，正是英伟达大幅回撤，迫使相关方尽快把黄仁勋请回去。文中还引 Ben Thompson 的观察：英伟达在相当程度上是围绕黄仁勋组织起来的「外骨骼」，创始人权力极大，也意味着巨大的关键人物风险。结论不是站队，而是承认：市场无关道德，它只关心利润和增长；你可以不喜欢这个过程，但需要看懂这个机制。
  • 关键方法/工具：用多年回报序列抵抗「最近几年的涨幅会自动延续」；把「市场想要什么」和「这件事公不公正」分开看。
  • 可行动点：给 2026 年的预期先减去「前三年平均涨幅」，改问：如果今年只是一个普通甚至偏弱的年份，自己的现金流和仓位还能否执行原计划。

4.3 没什么比价格更能改变情绪；努力是必要的，但不是财富的充分条件（优先监控）

  • 核心观点：@dollarsanddata 引用 Helene Meisler：「Nothing like price to change sentiment.」他随即嘲讽：不久前还那么看空，对上的已经是「4 月以来没见过的价格」。这不是在宣布趋势反转，而是在指出一个行为金融里反复出现的现象——叙事往往跟在价格后面，而不是走在前面。同一窗口他转述另一则观察：努力会按你承担的风险来回报。这就是为什么能看到不少身家超过 1000 万美元的企业主，却很少看到同等财富的建筑工人——高强度劳动是必要的，但不是积累巨额财富的充分条件。把两句话放在一起看更有用：短期情绪会被价格迅速改写；长期结果则和你承担了哪种风险有关，而不是和你有多忙有关。
  • 关键方法/工具：先看价格是否已经改写了自己的叙事，再决定要不要行动；把「努力程度」和「承担的风险类型」分开记账。

4.4 分析师降级往往是认真看的时候；牛市让人忘记估值（优先监控）

4.5 Meta 建模系列终篇：把算力账单和估值放在一起看（优先监控）

4.6 买在山顶之后，不同资产的「解套时间」差得很远

  • 核心观点：@TechFlowPost 连发两条和「时间」有关的观察。一条是：同样在山顶站岗，各市场处在完全不同的「受锤进度条」上——文中口径为，比特币已独自熬了约 413 天、回撤约 50.9%；黄金默默跌了近 300 天、回撤超过 30%；纳斯达克才见顶滑落约 48 天。每个市场有自己的熊途，对照历史上动辄数年的修复，这一轮可能都还在半山腰。另一条更直接：2000 年买在纳斯达克顶点的人，等回本等了约 15 年（文中写 5522 天）；2011 年追高黄金的人，在山顶站了将近 9 年；比特币虽然常在 2 到 3 年里收复前高，但中间有过超过 75% 到 80% 量级的回撤。它还提到一个历史统计：比特币跌破 200 周均线后的半年，加密总市值在所列举的案例里都高于跌破当周，并点到 2018 熊市低谷、2020 疫情和 2022 年 FTX。这些都是历史样本，样本有限，也不保证下一次仍是如此；更有用的是把「还要等多久」从情绪问题，改写成「这类资产历史上需要多大回撤、多长时间，我能不能真的熬」。

4.7 若 SpaceX 溢价换股收购特斯拉：短期可套利，长期持有者可能被稀释

  • 核心观点：@mylifeonmystyle 称自己已写过 18 篇反对特斯拉与 SpaceX 合并的文章，并在当天再算了一遍账。他的关键假设是：两家公司合并，长期并不会自动带来更高估值。文中以 SpaceX 125 美元、特斯拉 380 美元为基数，假设 SpaceX 以 25% 溢价全股票收购特斯拉、换股比例 3.8:1，得到合并前 SpaceX 市值约 1.70 万亿美元、过去 12 个月营收约 320 亿美元、市销率约 53 倍；特斯拉市值约 1.50 万亿美元、营收约 1036 亿美元、市销率约 14.5 倍；合并后总市值约 3.58 万亿美元、合计营收约 1356 亿美元、市销率约 26.4 倍（均为原帖测算）。他的推演是：溢价收购会使 SpaceX 股价走低、特斯拉涨到溢价附近，但总市值不必上升，短期套利者可以卖掉兑现，长期不卖的人合并后持有价值不变；若 2027–2028 年 Robotaxi / FSD 带来的成果被 SpaceX 股东分享，对长期特斯拉持有者是稀释；特斯拉已有盈利和现金流，合并后可能被用来支持 SpaceX 的资本开支，独立情况下本可计息的公司间安排，对特斯拉股东可能反而是损失。结论被他概括成：短期套利，中期用特斯拉的收益去换更长周期、也更不确定的 SpaceX 发展。这是对一种尚未兑现的并购假想的推演，不是对交易是否发生的判断。同一主题，@Money_or_Life_X 也提示不要做「冤大头」。

4.8 更低的低点，不一定等于卖压还在加强

  • 核心观点：@virtualbacon 观察到，比特币今年的低点更低了三次——2 月、6 月和上周六——但他说的动量分数却从 29 到 33，再到 35。在他看来，这是偏多的信号，因为卖压可能正在衰减。他同时补充了几条行为规则：不打算在熊市这么晚的阶段继续把精力放在做空比特币上，因为越往下，反弹可能越猛；没有借钱，交易所就不能强制平仓，于是问题会从「要不要做空」变成「加不加现货、还是继续拿着」；他在周二平掉了所有 AI 股票空头，并区分两类仓位——空头要经常兑现或加仓，不要变成「空头持有者」，比特币则只是拿着。这些是交易者的即时感受和规则，不是经过核验的动量模型，也不是对底部的判断。

5.3 市场没有道德，但它会强迫世界做出反应（优先监控）

  • 关键方法/工具：把睡前屏幕时间当成会改变生理节奏的「夜班」，而不是放松。
  • 可行动点：给手机设置一个固定的停用时间，先从提前 30 分钟开始，连续试一周，看早晨的清醒程度有没有差别。

6.3 屏幕时间退场，故事时间进场

  • 核心观点：@deewalkerbooks 把一条病毒视频的结尾改成了两句对立的话：Screen time out，Story time in。同一窗口他还问：线上读书社区里，自我帮助类书籍常被讨厌；如果不用书来自我教育，你用什么，为什么？这两条合在一起，像是在重新定义「输入」：不是增加更多刷到的片段，而是把时间还给完整的叙事和主动的学习。

6.4 上一代若不再提供可反叛的理想，下一代会更难形成自我（优先监控）

  • 核心观点：@robkhenderson 引用一段关于认同形成的话：上一代若在提供那些必须先于认同形成的、有力的理想上放弃了责任，下一代就更难完成自我建构——哪怕只是为了让年轻人有一套清晰的旧价值可以反叛。这不是育儿技巧，而是一个关于「原则是否还被认真对待」的观察：模糊的放任，并不自动等于自由；没有可对峙的框架，人有时更难长出自己的立场。
  • 关键方法/工具：检查自己是否还愿意把原则讲清楚，而不是用「让他们自己决定」回避示范。
  • 可行动点：若你在带团队、做父母或做自己的长期计划，试着写三条你愿意被反驳的原则，而不是只给弹性空间。
